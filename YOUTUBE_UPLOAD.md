# TRACE — YouTube upload package

## Title

TRACE — The Canvas Is the Prompt | OpenAI WebMCP Challenge

## Description

TRACE is a living reasoning surface shared by a person and an AI agent.
Circle an object to establish exact context. Cross out an assumption to reject
it. Through WebMCP, ChatGPT reads and transforms the same semantic artifact
instead of guessing from pixels or working in a disconnected chat box.

In this demo, TRACE turns an inclined-plane sketch into visible force vectors,
an in-place derivation, and animated motion. Removing friction recomputes the
result from 4.06 to 4.91 m/s². The same gesture language then expands an
oversimplified July 1914 causal arrow, compares source perspectives, and draws
a qualified counterfactual without pretending to predict an alternate past.

Live demo: https://trace-webmcp.callboard.workers.dev/
Source: https://github.com/guangyusong/trace-webmcp

Built with WebMCP, React, TypeScript, SVG, Vite, Cloudflare Workers, and Codex
for the OpenAI WebMCP Challenge.
